# Example pairs

Three rectified stereo pairs from our own OAK-D Lite, 640x400, 8-bit grayscale (recordings of 2026-03-29). Rectified with the camera's factory calibration.

- Rectified focal length: `--fx 471.049` (pixels)
- Baseline: `--baseline 0.07514` (metres)

| Pair | Scene |
|---|---|
| pair_01 | footpath between bushes and trees |
| pair_02 | tree trunk close to the camera, footpath, low wall |
| pair_03 | footpath under trees |
